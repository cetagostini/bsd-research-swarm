# Group H: Computational Approaches

## Mission

Use large-scale computation to verify, test, and discover patterns related to the Birch and Swinnerton-Dyer conjecture.

## Scope

This group focuses on the computational backbone of BSD research: verifying the conjecture for specific curves, building pipelines that compute every quantity appearing in the BSD formula, mining large databases for statistical patterns, and pushing the frontier of what is numerically tractable. All directions assume access to LMFDB, SageMath, Magma, PARI/GP, and high-performance computing infrastructure.

## Deliverables

- Verified BSD data for families of elliptic curves up to large conductor
- Open-source computational pipelines reproducible by the community
- Statistical analyses and conjectures derived from large-scale data
- Bounds and certifications with explicit error estimates
