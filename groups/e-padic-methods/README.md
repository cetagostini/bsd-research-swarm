# Group E: p-adic Methods

## Mission

Develop and apply p-adic analytic methods — p-adic L-functions, p-adic heights, p-adic Gross-Zagier formulae — to the Birch and Swinnerton-Dyer conjecture. This group bridges Iwasawa theory, p-adic Hodge theory, and computational number theory to extract arithmetic information from p-adic analytic objects attached to elliptic curves and, where feasible, abelian varieties.
